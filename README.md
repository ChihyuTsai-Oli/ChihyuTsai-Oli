## LoopFlow Series

> A complete design workflow system — though you're welcome to pick just the parts you need.

![LoopFlow Workflow](image/workflow.svg)

Built around the Rhino 3D model as the single source of truth, LoopFlow carries a project from schematic design (SD), through design development (DD), to construction documentation (CD). The wider LoopFlow series extends the same model data through two connected paths:

1. **Design & Documentation** — SD → DD → CD inside Rhino, from the 3D model to 2D Layout documentation &nbsp;( [LoopFlow](https://github.com/ChihyuTsai-Oli/LoopFlow) )
2. **Rendering** — Rhino 3D Model → [OctaneRender Sync](https://github.com/ChihyuTsai-Oli/LoopFlow_Rhino-to-Octane-Sync) / [Blender Sync](https://github.com/ChihyuTsai-Oli/LoopFlow_Rhino-to-Blender-Sync)

Each project has detailed documentation — or if you'd rather start with a quick overview, [browse the workflow playlists on YouTube](https://www.youtube.com/@Chihyu-Oli/playlists).
